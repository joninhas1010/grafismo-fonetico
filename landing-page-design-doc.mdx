# 3. Layout

## 3.1 Container

- Wrapper externo: `max-width: 1140px` (herdado do builder), mas o **conteúdo útil é uma coluna de 460px** (`width: 460px` em viewport ≥ 480px; 100% abaixo disso).
- A coluna é centralizada (`margin: 0 auto`); o fundo `#FFF6E3` ocupa a página inteira.
- Seções escuras (`#5A3522`) e verde (`#1A9940`) **cobrem apenas os 460px** da coluna — no desktop aparecem como uma “faixa” central sobre o creme.
- **Padding lateral padrão das seções: 22px** → largura útil de conteúdo = **416px**. Cards, imagens e botões ocupam 416px (ou 380px dentro de cards com padding).

## 3.2 Sistema de layout

- **Flexbox em coluna** para a pilha principal de seções. Não há CSS Grid no layout visível.
- Os chips do hero formam uma grade 2×2 (`display: grid; grid-template-columns: 1fr 1fr`, gap ≈ 8–12px, *inferido* pela medição: cada chip ≈ 204px de largura).
- Listas de benefícios são pilhas verticais (um item por linha), separadas por linhas finas.

## 3.3 Espaçamento vertical padrão

| Contexto | Padding |
|----------|---------|
| Hero | `36px 22px` |
| Seção escura com título | `40px 0 36px` (título tem padding lateral 22px) |

| Seção de depoimentos | `36px 22px 32px` |
| Seção de garantia | `40px 22px` |

## 3.4 Breakpoints

Detectados nas *media queries* da folha de estilos:

| Query | Uso |
|-------|-----|
| `(min-width: 768px)` | Ajustes de tablet/desktop do builder |
| `(max-width: 1024px)` | Tablet |
| `(max-width: 480px)` | Mobile — coluna passa a 100% da largura |
| `(prefers-reduced-motion: reduce)` | Desativa animações |

Na prática, o design é **um layout só** (mobile) que apenas se centraliza em telas maiores.

# Limitações e pontos a validar

1. **Estados `:hover` / `:focus` / `:active`**: a leitura das regras CSS desses estados foi bloqueada no ambiente, então os valores de hover e active acima são *inferidos* a partir da propriedade `transition` (transform, box-shadow, filter).
2. **Seções não medidas em detalhe:** depoimentos, carrossel de prova social, garantia, bio da autora e rodapé foram mapeados por posição, cor de fundo e padding; textos internos e tamanhos de imagem exatos podem variar.
3. **Cores de ícones de check** (verde-escuro) foram estimadas visualmente em screenshot (~`#3D5A2A`), não lidas do CSS.
4. **Chip grid (2×2):** a largura de 204px por chip foi medida; o `gap` exato não foi lido.
5. Ativos de imagem (colagem de pratos, foto da autora) são conteúdo do infoproduto — substitua pelos seus próprios.
